# Evidence desk

Use this skill before writing factual claims or when a claim is challenged.

## Method

1. Turn the brief into the smallest set of research questions.
2. Use the deferred Exa connector for current web search and page retrieval.
3. Delegate independent questions when parallel work will reduce uncertainty. Give each subagent one question and require source links in its return.
4. Prefer primary sources. Use a secondary source only when it adds necessary context.
5. Record URL, title, publisher, access time, supporting excerpt, and reuse status.
6. Connect each factual script claim to one or more source records.
7. Mark a claim conflicted or unsupported when the sources do not justify it.
8. Save the evidence ledger before saving the content package.

Do not download a creator-provided verified excerpt again unless asked to recheck it.

## Conflicts

State what differs, which source is closer to the original evidence, and what wording remains defensible. Do not average incompatible numbers or hide uncertainty.

## Handoff

Return only the source records, claim decisions, and unresolved questions the producer needs. Keep research narration out of creator chat.
