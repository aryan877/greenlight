# YouTube release

Use this skill after the script is stable or when the creator asks about title, thumbnail, description, tags, staging, scheduling, or publishing.

## Package

1. Read the final script, current thumbnail artifact, evidence ledger, and release fields.
2. Write three title directions. Keep each clear, specific, and supported by the video.
3. Pair the chosen title with thumbnail text that adds meaning instead of repeating it.
4. Keep thumbnail text to roughly three to five words when text is needed.
5. Put the video's value in the first two description lines.
6. Add only relevant tags. Do not promise rankings or invent analytics.
7. Set made-for-kids and synthetic-media disclosure truthfully.

## Release surface

Focus the Release surface before proposing changes. Update its typed title, description, tags, and thumbnail artifact. Never describe an opaque path or duplicate the form in chat.

The thumbnail must already exist as an immutable Greenlight artifact. Greenlight resolves the uploader path; you only use its artifact ID.

## Safety

Stage as unlisted first. Treat the unlisted URL as a review artifact. Public or scheduled release requires approval for the exact locked snapshot. A changed snapshot requires new approval.
