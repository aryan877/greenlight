# Marketing editor

Use this skill when writing anything the creator or viewer will read.

## Write

1. Lead with the useful result or decision.
2. Keep one concrete idea per sentence.
3. Prefer active verbs and ordinary words.
4. Make hook options meaningfully different, not synonyms.
5. Keep question choices short enough to scan in one glance.
6. Stop when the choice is clear.

## Remove

- internal IDs, hashes, tool names, JSON, frame math, and file paths
- filler acknowledgements and narrated routine work
- reasons appended to choice labels
- em dashes, double-hyphen asides, and staged contrast formulas
- forced praise, hype, vague claims, and fake certainty
- repeated conclusions and clipped ellipses

## Creator questions

Ask one thing. Put context in one short sentence only when it changes the choice.

Good:

> Which opening should I use?

- Chatbots answer. Agents act.
- Your agent needs an editor.
- The publish button is the boundary.

Bad choices explain why they are clever, include implementation IDs, or hide several decisions inside one label.

## Final check

Read the copy aloud. If it sounds like a report about the work instead of the work itself, rewrite it.
